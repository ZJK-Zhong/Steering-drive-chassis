# chassis

## 总体说明

本应用控制四个M3508驱动电机和四个GM6020舵向电机，使用修改版 `E:/RM/rm-sentry`
的任务、消息中心、电机模块和INS。云台、发射应用由另一块板承担，已从本工程移除。

应用只设置电机目标，原 `MotorControlTask` 负责闭环和CAN发送。
控制消息由本板 `RobotCMDTask` 通过 `chassis_cmd` 发布；反馈通过 `chassis_feed` 返回。

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `chassis.c` | 模式处理、保护判定、坐标变换、反馈反算和轮组目标更新 |
| `chassis.h` | 对外初始化/任务接口，以及调试结构定义 |
| `swerve_config.h` | 机械零位、几何与传动参数、控制增益、限幅和超时阈值 |
| `../../modules/swerve/swerve_kinematics.c` | 四轮速度矢量、最短转向和驱动反转算法 |

## 运行流程

初始化由 `RobotInit` 调用 `ChassisInit` 完成，随后创建原框架任务。

每一轮机器人任务先执行CMD，再执行底盘：

1. 复制八电机应用所需的反馈，计算在线状态，取得INS快照。
2. 从消息中心取出本轮控制消息，检查数值、模式、电机和必要的INS状态。
3. 无力或保护条件成立时停止八电机；有效目标进入模式处理。
4. 小陀螺角速度先按实际任务间隔爬升，再叠加陀螺仪角速度反馈修正。
5. 按参考系转换平移目标，调用 `SwerveSolve` 得到四组轮速与舵角。
6. 对四轮同比例限速，再按舵向误差的余弦降低驱动目标，更新电机参考值。
7. 更新功率限制，通过消息中心发布由实际轮速、舵角反算的底盘反馈。

## 外部接口与类型

- `ChassisInit(void)`：BSP初始化后、创建任务前调用一次，注册电机、INS和外围。
- `ChassisTask(void)`：由机器人任务周期调用，不应从其他任务并发调用。
- `get_referr_data_pr(void)`：返回本应用持有的裁判系统数据，不转移所有权。
- `SwerveDebug_s`：调试观测结构，不参与通信。各字段单位和更新时间含义见头文件。
- `Chassis_Ctrl_Cmd_s`、`Chassis_Upload_Data_s`：位于 `robot_def.h`，沿用消息中心的控制/反馈契约。

原机器人任务每轮末尾 `osDelay(5)`；实际执行间隔还包含任务计算与调度时间。
底盘按实际毫秒间隔计算角加速度，不假定每轮恰好为5ms。

## 私有函数与变量

| 名称 | 作用 |
| --- | --- |
| `drive[4]` / `steer[4]` | 驱动/舵向电机实例，索引为左前、右前、右后、左后 |
| `steer_feedback_deg[4]` | 编码器校零并修正方向后的多圈舵角，也是GM6020角度环反馈 |
| `target[4]` | 解算结果缓存，全零速度时保留上一轮舵角目标 |
| `motor_online` | 检查是否收到有效反馈，以及距最近一帧是否超时 |
| `spin_reset` | 复位旋转PID、角速度参考和平移参考航向 |
| `stop_all` | 将八电机置停止状态，复位目标缓存和旋转状态 |
| `update_feedback` | 复制反馈、反算车体速度并读取INS状态 |
| `command_valid` | 校验目标有限数、幅值和模式编码 |
| `apply_targets` | 转换单位/方向、调用解算、限幅补偿并更新电机目标 |

## 坐标、单位与轮序

| 数据所在位置 | X / Y方向 | 平移单位 | 旋转单位 |
| --- | --- | --- | --- |
| CMD、底盘目标/反馈 | X前、Y右 | mm/s | rad/s，俯视逆时针为正 |
| `SwerveSolve` 输入 | X前、Y左 | m/s | 度/秒，俯视逆时针为正 |
| 轮组目标 | 校零后的舵向正方向 | 驱动转子rpm | 舵向多圈角，度 |
| 原 `measure` | 电机自身方向 | `speed_aps` 为转子度/秒 | `total_angle` 为转子多圈角，度 |

应用进入解算时将平移乘0.001、Y取反、角速度由rad/s转为度/秒。
电机实际转子rpm为 `measure.speed_aps / 6`，再乘输出轴/转子减速比及轮周长，才能得到轮缘m/s。

轮序与零位必须对应，具体CAN总线、ID和零位见 `swerve_config.h` 及根目录说明。

## 小陀螺参考系

小陀螺的平移X正方向是进入模式时的底盘朝向。
持续旋转时用“当前INS航向 - 入口航向”变换摇杆平移速度；改变左拨杆不会重新捕获航向。
退出后再进入才重新捕获。转速反馈修正控制旋转速度，不是绝对位置或绝对航向闭环。

## 使用与调试

上电保持底盘静止，等待原BMI088校准；右下解锁后再进入遥控或小陀螺。
先架空检查轮序、零位、舵角目标与实际方向，再落地低速验证。

Watch入口：

```c
swerve_debug
drive[0]->measure
steer[0]->measure
```

对照 `wheel_target_rpm` / `wheel_actual_rpm` 和 `steering_target_deg` / `steering_actual_deg` 判断跟踪情况。
`command_online` 只表示本轮收到CMD消息；遥控失联时CMD仍会发布无力消息。
电机读取临界区只避免单个结构读到更新一半的数据，不保证八电机反馈在同一时刻采样。

## 注意事项

- 任一电机反馈超时会停止全部八电机；电机任务还独立检查目标及反馈是否超过20ms。
- 小陀螺要求有效INS；IMU长期航向漂移、轮组零位和地面打滑仍会影响实际运动。
- 无力由电机停止状态实现，CAN控制量为零，不等于轮速环给零速时的制动。
- 当前本地遥控只发布车体系遥控和入口参考系小陀螺，跟随/导航没有本地入口。
- 原功率模型只覆盖驱动电机，尚未包含舵向功耗和重新标定结果。

构建与软件验证方式见 [README_STEERING.md](../../README_STEERING.md)。
